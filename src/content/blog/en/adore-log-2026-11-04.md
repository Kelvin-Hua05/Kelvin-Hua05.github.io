This is the first development log for [ADoRE-DoE](https://github.com/Kelvin-Hua05/ADoRE-DoE). The project is pre-alpha: no algorithm has been implemented yet.

## What I did

- Wrote up the architecture, research methodology, roadmap and algorithm-decision documents.
- Created the package skeleton (v0.0).

## Design decisions

- **Active learning is separate from final RSM modelling.** Module 1 can run on its own.
- **GA is not part of active learning.** It is reserved for final process-parameter optimisation.
- **Residual correction uses out-of-fold residuals** to avoid in-sample leakage.

## Open questions

- How to define the traditional-DOE baseline.
- How to normalise multiple responses.
- Bias when cross-validation is used in the stopping rule.
- Model mismatch between the GPR surrogate and the final RSM.

## Next

Start v0.1: core data structures and Plackett-Burman screening.
